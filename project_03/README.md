# Arduino Starter Kit R4 - Project 03 - Chill-o-Meter

## Decscription

This project reads the sensor's output and uses it to turn LEDs on or off, indicating how much heat the sensor is detecting. <br>The TMP36 module changes its voltage output directly proportional to temperature in degrees Celsius.

### Code notes:
```
Voltage will range from 0 to 5 volts. And may include fractional values (for exlample 2.5V). Voltage is calculated by dividing sensorVal by 1024.0 and then multiplying by 5.0.
```
