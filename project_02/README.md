# Arduino Starter Kit R4 - Project 02 - Spaceship Interface

## Decscription

Simple control panel that could have been a spaceship interface in a 1970s science fiction movie. <br>When the switch is pressed, the green led will turn off and the 2 other lights will start blinking.
